# Как добавить сервис

1. Создай отдельную репу через фабрику в `portable-agent/infra`.
2. Подключи подходящий общий workflow из `portable-agent/.github`.
3. Собери и опубликуй образ в GHCR.
4. Запусти `scripts/new-service.ps1` в этом репозитории.
5. Замени `change-me` на immutable tag или digest и укажи только нужные `secretRefs`.
6. Открой PR. После проверок Argo CD увидит новый каталог автоматически.

Генератор не перезаписывает существующий сервис и проверяется отдельным тестом. Общий chart
даёт непривилегированный контейнер, read-only filesystem, лимиты ресурсов, probes и закрытую
сетевую политику по умолчанию.
