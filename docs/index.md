# Deploy

Репозиторий начинает инженерный полигон Portable Agent. Первый результат — минимальный Helm chart,
который устанавливается и проверяется в одноразовом k3d-кластере.

Следующие пакеты после ревью:

1. values для `local`, `dev` и `stage`;
2. chart реального сервиса без секретов;
3. Argo CD только после стабильного локального smoke;
4. preview namespace для pull request.
