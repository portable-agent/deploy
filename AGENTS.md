# Правила для AI-агентов

## Назначение

Репозиторий хранит декларативную доставку Portable Agent: Helm, k3d smoke-тесты и позже Argo CD.

## Границы

- не добавляй бизнес-код сервисов;
- не храни секреты и настоящие пользовательские данные;
- не добавляй production-настройку до отдельного ADR;
- скрипт не должен удалять кластер, который он не создал;
- новая технология сначала получает тест и ADR.

## Структура

- `charts/` — Helm charts;
- `scripts/` — короткие проверки;
- `docs/` — русская документация;
- `.github/workflows/` — CI.

## Команды

```powershell
task verify
task test:e2e
```

## Правила изменений

1. Сначала измени тест или проверку и получи ожидаемую ошибку.
2. Добавь минимальный YAML для зелёного теста.
3. Используй простые имена: `base`, `local`, `smoke`, `ready`.
4. Один pull request меняет один инженерный сценарий.
5. Обновляй README и docs вместе с командами.
6. Не продолжай к Argo CD, пока локальный smoke не зелёный.
